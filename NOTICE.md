## Why GPL, and not something else

It is not a preference; the code it builds on requires it. Parts of PakuPort are derived from
**DOSBox-X**, which is licensed under GPL-2.0 *or any later version*. They are marked in the
code with the DOSBox-X file and line they come from. The GPL requires derived work to be
distributed under the GPL and forbids adding restrictions, so PakuPort cannot be offered under,
for instance, a "non-commercial only" license. DOSBox-X's "or later" clause is what allows
GPL-3.0, which in turn allows including the GPL-3.0 xBRZ scaler.
