1. DOSBox-X  (derived code, in the source tree)
------------------------------------------------
Source  : https://github.com/joncampbell123/dosbox-x
License : GNU General Public License, version 2 or (at your option) any later version

Parts of the platform layer (src/PakuPort.Core/Platform/, and some CPU and timing details) are
ported from DOSBox-X: video BIOS tables and fonts (int10_*.cpp), keyboard scancodes and BIOS
keyboard rules (keyboard.cpp, bios_keyboard.cpp), DAC expansion (vga_dac.cpp), CRTC semantics,
the OPL2 synthesizer (dbopl.cpp), the Sound Blaster DSP (sblaster.cpp), PIT/PC speaker timing,
DOS file-system behaviour (drive_cache.cpp, dos_files.cpp), and more. Each place carries a
comment naming the DOSBox-X file (and usually the line) it comes from. Because DOSBox-X allows
"any later version", the combined work is distributed under GPL-3.0-or-later.


2. xBRZ  (derived code, in the source tree)
--------------------------------------------
Author  : Zenju
Source  : as included in DOSBox-X (src/libs/xBRZ/)
License : GNU General Public License, version 3

src/PakuPort.Core/EscaladoXbrz.cs is a C# translation of the RGB path of xBRZ.


3. Scale3x  (algorithm only)
-----------------------------
src/PakuPort.Core/EscaladoPixelArt.cs implements the Scale3x algorithm, which is in the public
domain. No third-party code is included.
